## 2.Context

After understanding which language we are going to use, it is interesting to understand if we are going to use a framework and which framework we are going to use to better use the chosen language. Thinking about practicality and learning, Spring was the framework chosen to accompany Kotlin

## 3.Justifications 
### 3.1 A widely used framework
Spring is a very common and widely used framework. Its knowledge base is large and there are already several solutions to possible problems that we will face to create a new solution. Spring is a framework initially created for Java that was born in 2003 and has since been expanded and updated to the modern day. Most Java web applications use spring, so it is a great and safe framework to use

### 3.2 A Solid knoledge base
Spring is a framework with a solid knoledge base. With more than 20 years of existence, Spring has already become a reliable framework to work. A lot of problemas have already been solved with spring, and we have a large documentation for study and for improve our skills

## 4.Decision
Considering all the previous statements, we chose to use spring in this project, both because it is a framework widely used around the world, but also because it has a large knowledge base.
