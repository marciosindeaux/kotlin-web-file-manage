## 2.Context
When we think about creating some kind of system, we usually start by thinking about what we are going to do. Normally this is a good approach, but taking a step back, we need to think about whether what we are going to do will be maintainable and whether other people will be able to adapt to this new code base. With this in mind, the Kotlin language was chosen

## 3.Justifications 
### 3.1 An easy language to Understand and learn
Kotlin is a really easy language to understand. If you had some contact with any other language that uses a functional structure or if you worked with more standard languanges, kotlin is gonna be easy to understand and learn. Often, kotlin needs a short time to leard and understand. 

### 3.2 An easy language to maintenance
Due to its ease of learning, Kotlin is a language that can easily be maintained by someone else, thus ensuring that the software does not become outdated.

## 4.Decision
Taking into consideration all the points presented, in this project we will use Kotlin as the main language, paying close attention to its ease of learning and its easy maintenance
