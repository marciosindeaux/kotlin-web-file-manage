## Story Statement

` I, as an user, want to to be able to create a folder in my root folder as well as create subfolders within that directory.`

## Acceptance Criteria

- User can create a folder in the root directory or can create subfolders inside folders.

## Technical notes

- The user cannot create a folder with name `root`
- The user cannot create two folders with the same name in your own current navigation directory.
- The user can create two folder with the same name if they are not in the same depth on the directory tree
