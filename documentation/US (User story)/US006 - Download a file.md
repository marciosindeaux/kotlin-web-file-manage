## Story Statement

` I, as an user, want to to be able to download files from server with the encrypted name`

## Acceptance Criteria

- A file has to be downloaded from server using the default name if the person who are accessing is the owner.
- A file has to be downloaded from server using the encrypted name

## Technical notes

- The file must be searched through its encrypted name
- When the download is complete, the original file name should be restored.
