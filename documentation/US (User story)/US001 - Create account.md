## Story Statement

` I, as an user, want to to be able to sign-up into the system, want to log-in and want to be able to see my home page as is my root folder.`

## Acceptance Criteria

- User must have the option to create an account

## Technical notes

- The user can create an account with password or with 2FA via e-mail.
- The user cannot create two accounts with the same email
- The user needs to confirm your own identity with confirmation e-mail.
- If the user cannot confirms your own identity in 7 days, all the account's data is gonna be deleted.
