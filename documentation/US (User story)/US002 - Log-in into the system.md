## Story Statement

` I, as an user,  want to log-in and want to be able to see my home page as is my root folder.`

## Acceptance Criteria

- User can log-in into the system
- After the log-in, usar must see your own root folder and home page

## Technical notes

- The user can log-in into their account with 2FA via Email. This is the preferred method.
- The user can log-in into their own account with password. This is a secondary method.
- The user needs to be in the 7 first days or have a valid confirmed account to use e-mail 2FA.
